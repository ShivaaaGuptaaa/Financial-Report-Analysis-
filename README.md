Financial Statement Analysis

Project Overview

This project evaluates the financial performance and position of Sun Pharma, Dr Reddy, Lupin, Cipla using its published financial statements for [Financial Years].

The analysis focuses on profitability, liquidity, solvency, operational efficiency and cash flow generation.

Objectives

- Analyse trends in revenue, expenses and profitability.
- Evaluate key financial ratios.
- Examine operating, investing and financing cash flows.
- Assess working capital management and financial sustainability.
- Draw business insights to support financial decision-making.

Methodology

- Reviewed published annual reports and financial statements.
- Calculated and compared relevant financial ratios.
- Examined year-on-year movements in financial performance.
- Evaluated cash flow trends and their implications.

Tools Used

- Microsoft Excel
- Microsoft PowerPoint
- Financial statements and annual reports

Key Findings

- Profitability
- Liquidity
- Leverage
- Cash Flow
- Overall Assessment
